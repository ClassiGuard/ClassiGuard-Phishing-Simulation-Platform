# 📚 Public Product Documentation — ClassiGuard CyPhish

Welcome to the public documentation directory for **ClassiGuard / CyPhish**. The materials in this directory are intended for distribution alongside the product release to assist system administrators, security engineers, and DevOps teams with deploying and operating the platform.

---

### Included Documents:

1. **[`CYPHISH_ARCHITECTURE_AND_DEPLOYMENT_GUIDE.md`](./CYPHISH_ARCHITECTURE_AND_DEPLOYMENT_GUIDE.md)**
   * Comprehensive architectural reference, network diagram, workflow descriptions, and step-by-step production installation guide.

2. **[`CyPhish_Implementation_Guide.pdf`](./CyPhish_Implementation_Guide.pdf)**
   * Formatted deployment manual covering hardware/software prerequisites, SSL/TLS certificate setup (CSR vs. Self-Signed), environment variables, and Docker container orchestration.

3. **[`CyPhish_Feature_Presentation.pptx`](./CyPhish_Feature_Presentation.pptx)**
   * High-level feature presentation overview for stakeholders, security trainers, and administrators.
